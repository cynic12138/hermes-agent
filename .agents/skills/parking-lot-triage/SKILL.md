# Parking Lot Triage

## 工作流

1. 确认想法不属于当前范围或阶段，不立即实现。
2. 在 `docs/PARKING_LOT.md` 中记录或更新。
3. 每条包括：想法、来源、价值、当前不做原因、前置条件、建议阶段、重评触发条件。
4. 保持简洁、可追踪，不承诺未经批准的日期。

## 约束

- 不创建占位代码或空接口。
- 不提前引入依赖。
- 不为未来可能需求修改当前架构或预留复杂扩展点。
- 只修改 Parking Lot；若不存在可创建，但不得借机修改业务代码。
