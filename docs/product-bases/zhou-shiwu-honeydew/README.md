# 周十五蜂蜜露产品资料基座

- 建立日期：2026-07-14
- 当前状态：`DRAFT_EVIDENCE_BASE`
- 产品标识建议：`zhou-shiwu-honeydew`
- 适用项目：Hermes Product Creative Plugin

## 基座定位

本目录是“周十五蜂蜜露”的**外部证据候选基座**，用于把公开检索、用户确认和后续公司正式资料放在同一套可追溯规则下管理。

它当前**不是**预制 Product Brain，也不是把互联网内容批量灌入 Product Brain 的入口。Product Brain 应从空白骨架开始，由 Hermes 在与用户的自然语言对话中主动发现缺口、索要资料、复述理解、提出候选字段；只有经人工审核的字段，才允许通过 proposal/apply 流程进入正式 Product Brain。

公开网络资料默认只进入 Evidence Inbox 或 Inspiration，不得因“多个网页都这样写”而自动成为正式产品认知。

## 当前可确认的边界

- **CONFIRMED** 项目第一条真实产品验证线选择“周十五蜂蜜露”。
- **CONFIRMED** 主要交付物是实际生成的产品图片和短视频，不以小红书文案为交付物。
- **CONFIRMED** 商品包装、Logo、管体和包装文字必须保持原样；AI 只生成背景、场景、人物、装饰元素和剧情。
- **CONFIRMED** 第一版视频基线为 9:16、约 15 秒、每轮 3 个版本，持续根据人工反馈迭代质量。
- **CONFIRMED** 当前不做矩阵化批量生产。
- **INFERRED** 多个相互独立的公开商品页将该产品描述为外用蜂蜜露，但尚缺当前实物包装和正式说明书，因此不能升级为正式产品事实。
- **UNKNOWN** 最新包装、完整规格、成分、适用人群、使用方法、品牌主体、生产主体及可合法使用的宣称。
- **CONFLICTED** 仓库内多份历史测试把该产品写成“蜂蜜/果蜜饮品、夏季补水”，与公开资料明显冲突，禁止复用为真实产品认知。

## 使用规则

1. 公开网页先登记为 evidence，不直接改 Canonical Product Brain。
2. 每个事实必须绑定来源、适用 SKU/包装版本、抓取时间和审核状态。
3. 来源冲突时不静默覆盖；冻结冲突字段并创建人工审核项。
4. 社交平台内容仅用于热点、钩子、场景和表达研究，不证明产品事实。
5. 第三方图片只保留来源链接和观察记录；未经授权不复制到可提交的正式素材目录。
6. 后续收到当前实物包装、说明书和公司正式资料后，应按 [ASSET_INTAKE.md](ASSET_INTAKE.md) 入库并重新审阅本目录。
7. 新建产品时先创建空白/最小 Product Brain，不把本目录的候选值自动填入 canonical 字段。
